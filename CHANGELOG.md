## [0.1.0] - 2026-07-22

### Added

- Static HTML/CSS mobile-screen discovery, device configuration, and scaffolding.
- Deterministic Playwright screenshots, layout validation, and machine-readable
  reports.
- A local phone-sized viewer with screen navigation and review annotations.
- UX and visual checkpoint tracking for delivery-readiness checks.
- A reusable Mocklens design skill and a checked example project.
